This is a [TanStack Start](https://tanstack.com/start) project built with Vite, React, and TypeScript.

## Getting Started

First, run the development server:

```bash
pnpm dev
# or
npm run dev
# or
yarn dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

You can start editing the page by modifying `src/routes/index.tsx`. The page auto-updates as you edit the file.

## Tech Stack

- **Framework**: TanStack Start with React
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Backend**: Convex
- **Deployment**: Cloudflare Pages

To learn more about the technologies used, take a look at the following resources:

## Deploy on Cloudflare Pages

The project is configured to deploy to Cloudflare Pages:

```bash
pnpm run deploy
```

This will build the project and deploy it to Cloudflare Pages.
