### Pico — local-first developer tool (2026)

- GitHub: https://github.com/alivault/pico
- Package: https://www.npmjs.com/package/@alivault/pico
- Run the browser workspace with `npx @alivault/pico`.
- Pico is open source under the AGPL-3.0 license.

Pico is a fast, keyboard-first workspace for local Pi coding-agent sessions. It
grew from Ali's observation that an effective coding-agent product needs more
than a transcript: it must make sessions, project context, Git state, pending
instructions, and concurrent work understandable and controllable.

The Pico server runs on the developer's machine, loads the Pi SDK, works with
local project files, executes Git operations, and lets the SDK manage model
provider credentials. Browser and native clients connect to this local runtime.
The browser app uses TanStack Start, React, and TypeScript. Native macOS and iOS
clients use SwiftUI. HTTP/JSON and Server-Sent Events provide shared contracts
and live updates across clients.

Pico can organize active and historical sessions by project; show files, diffs,
branches, commits, repository status, and unpushed work; queue or steer prompts;
attach files and diff comments; switch models; and support Git actions such as
staging, discarding, committing, pulling, and pushing. Its streaming design
uses an initial reliable state baseline followed by patch-friendly updates.

The architecture deliberately keeps agent, filesystem, Git, and credential
behavior in the local runtime while each client owns presentation and
platform-specific interaction. The current security boundary is a trusted
local machine or trusted network. Pico does not currently present an
unauthenticated public deployment as a supported use case.

Ali's stated lessons from Pico include:

- The workspace around AI matters as much as the model.
- Streaming is fundamentally a state and data-modeling problem.
- Local-first products need clear, honest security boundaries.
- Shared behavioral contracts can support distinct browser, macOS, and iOS
  experiences without forcing identical interfaces.
